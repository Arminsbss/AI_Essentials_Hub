# Sources and Evidence Register

This register contains 56 primary references used in the refreshed hub. Public documentation and original paper abstracts were reviewed during 12–13 September 2026. A living-documentation entry has no single fixed publication date established here; the review date is not a publication date. Paper entries retain original submission and revision dates when available.

Official capability descriptions are not independent comparative benchmarks. Historical papers support methods and evaluation ideas, not current-model rankings. Provider model names and cloud terminology are point-in-time observations. See [RD_Report.md](RD_Report.md) for conflicts and limitations.

The local baseline is `AI_Essentials_Hub-main.zip`, supplied for this update. It contains 17 Markdown files and LICENSE, with no Git history. The original 2024 MIT copyright notice was preserved. No public URL for that archive or verified upstream commit is asserted.
